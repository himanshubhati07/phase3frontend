# html

Single-page Svelte conversion of the "XCore — Onboard your organization" HTML design, served at `/`.

## Tech stack
Svelte 4 + TypeScript, Vite, svelte-routing.

## Getting started
```
npm install --legacy-peer-deps
npm run dev
```
Then open http://localhost:39629

## Project structure
- src/design: the converted page (components, html sections, styles) copied unchanged
- src/pages: NotFound catch-all page

## Known differences
None known.
