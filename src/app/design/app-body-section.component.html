Policy & Documents

Suite-wide governance, terms of service, data handling rules, and per-tool policy documents.

🛡 Xccelera AI Suite-wide Policies

🔒
Suite Data Handling
Xccelera AI never stores agent session data beyond the active job; each tool's own retention policy governs its workspace.
⚖️
Terms of Service
Governs use of the Xccelera AI orchestration platform and all embedded tools.
🛡️
Security & Access
Role-based access is enforced via User Management — approval and tool assignment gate every workspace.
🗃️
Data Retention
Run logs are retained for 90 days. Harness Memory items are retained until explicitly archived or expired by a Super Admin.
🔑
API Key Policy
Keys expire after 90 days by default. Super Admins can extend expiry per key. Revoked keys cannot be restored.
